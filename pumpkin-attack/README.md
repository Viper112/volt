# Pumpkin Attack

Remotion animation that brings the pumpkins in a group photo to life and has them leap at the people.

## Preview

```bash
npm install
npm run dev
```

Open the `PumpkinAttack` composition in Remotion Studio (`http://localhost:3000/PumpkinAttack`).

## Composition

- **ID:** `PumpkinAttack`
- **Size:** 1080×1440 @ 30fps
- **Length:** 8 seconds

Pumpkin cutouts are extracted from the source photo. Glowing spirit copies materialize over the real pumpkins, then leap and bounce at each person's face with camera shake and impact bursts.
