# VOLT

A Kick-style live streaming platform: dark UI, neon green accents, live browse, real-time chat, and browser-based Go Live over WebRTC.

## Run it

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

Demo account: `demo` / `demo123`

## What you get

- Home feed with featured carousel, categories, and live rows
- Browse livestreams, categories, and clips
- Channel pages with player, follow, and live chat
- Search across channels, categories, and titles
- Following feed (after login)
- Go Live from camera or screen share — viewers watch in real time
- Catalog channels play sample videos so the site feels populated immediately

## Stack

Vite, React, TypeScript, Tailwind CSS, Express, Socket.io, WebRTC.
